# roblib_floorplan

- I keep this repo in sync with the most current version of the file: <https://github.com/rdrew/roblib_floorplan>
- The master file was developed in Adobe Illustrator, but due to the current annoying state of Adobe's subscription plans I've migrated the master to Vectorcraft, a free open-source Illustrator clone that runs on all platforms (<https://getartcraft.com/apps/vectorcraft>)
- The document requires "Pill Gothic 300mg" font to be istalled on your local machine to display properly for editing and export. There is a copy of the 2 font variations in the '/font' dir.
- I try to keep the most current usable versions for print and web use on the '/exports' directory (which don't need the software or fonts installed)
